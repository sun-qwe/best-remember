# 决策记录

只记「以后会想翻案」的决定，不是日记。一句话日记进 `journal/`，这里只放值得留理由的。

## 什么时候写

- 选了 A 没选 B，而 B 也说得通
- 定了某个约定：命名、目录结构、接口形态、数据格式
- 推翻了旧决定（新记录里写清推翻了哪一条、为什么改主意）

## 文件格式

文件名：`YYYY-MM-DD-短标题.md`

```
# <决定了什么>

- 日期：YYYY-MM-DD
- 状态：生效 / 已废弃（被 <哪条> 取代）

## 背景
<当时面对什么问题，两句话说完，不要写历史>

## 决定
<一句话，能直接执行的那种>

## 为什么
<真正的原因，不是事后编的理由>

## 放弃了什么
<没选的方案 + 它的好处。这一节最重要——它决定以后要不要翻案>
```

## 检索

不需要索引文件，`grep -ri "关键词" decisions/` 就行。智能体也被要求这么做。
