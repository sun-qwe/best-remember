# 工作日志（追加式）

每台机器一个文件：`journal/<机器名>.md`。**只追加，不改历史。**

## 什么时候写

一次任务收尾时，最多 3 行：

```
## 2026-02-13 DESKTOP-XXX
- 做了：把 brain 仓库接进了 Claude Code 和 Codex
- 定了：入口用写路径而不是符号链接
- 下次：第二台机器还没 clone
```

没有"定了"或"下次"就省掉那一行。**别写流水账**，流水账没人回看。

## 为什么按机器分文件

两台机器同时写不会冲突。合并和蒸馏是人工每周做的，不自动。

## 怎么用

- **接续上次**：新会话让它读最新几条 journal，比重新解释一遍快得多。
- **蒸馏**：每周把这里和 `inbox.md` 里有长期价值的东西挑进 `me/` 或 `projects/`，
  然后在这行下面记一笔 `<日期> 已蒸馏`。日志本身不用管，它只是原料。
- 半年以后可以 `git mv` 旧的进 `journal/archive/`，保持最新文件短。
